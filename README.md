# Fundamentos de Desarrollo Web: Crea tu primera página con HTML y CSS

## Resumen del Curso

Este curso de 1 hora introduce a estudiantes de secundaria a la creación de sitios web sencillos con **HTML** y **CSS**. A lo largo de 7 lecciones cortas aprenderás qué es una página web, cómo se estructura su contenido y cómo darle estilo, hasta construir tu propia **página de perfil personal**. **¡No requiere descargas!** Solo abre tu navegador web.

**Duración total**: ~60 minutos
**Público objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación
**Prerrequisitos**: Ninguno
**Herramientas necesarias**: **¡Solo tu navegador web!** (Chrome, Firefox, Safari o Edge)
**Editores en línea**: [CodePen](https://codepen.io), [JSFiddle](https://jsfiddle.net) y [Replit](https://replit.com) (gratuitos)

**📂 Repositorio de código fuente**: [https://github.com/upc-pre-202620-1asi0730-8150-GlitchLab/webdev-course-fabric](https://github.com/upc-pre-202620-1asi0730-8150-GlitchLab/webdev-course-fabric)

### ¿Qué lograrás al terminar?

- Explicar qué es un sitio web y cómo funcionan juntos HTML y CSS.
- Escribir la estructura básica de una página HTML.
- Usar encabezados, párrafos, listas, imágenes y enlaces.
- Dar estilo con colores, fuentes, bordes y centrar contenido con CSS.
- Publicar y compartir tu propia página de perfil.

### ¿Cómo usar este curso?

1. Mira cada lección en orden: cada una se basa en la anterior.
2. Cuando veas el ícono ⏸️ en el video, **pausa y practica** en el editor en línea.
3. Abre el enlace **Práctica** de la lección: el código inicial ya está cargado.
4. Si te atascas, compara tu trabajo con el ejemplo terminado de la carpeta `/completed-examples`.

## Secuencia de Lecciones

### Lección 1: ¿Qué es un sitio web? (5 minutos)
- **Descripción**: Descubre de qué están hechas las páginas web que usas todos los días y qué papel cumplen HTML y CSS.
- **Enlace**: <a href="https://youtu.be/ugn0V7no5NU" target="_blank">Ver la lección</a>
- **Consejos clave**: Sitio web = Contenido (HTML) + Estilo (CSS). El navegador "lee" el código y lo convierte en lo que ves.
- **Práctica**: [Explora tu primer código](https://codepen.io/PENDIENTE-L1) 👈 **¡No necesitas registrarte!**

### Lección 2: Estructura HTML básica (8 minutos)
- **Descripción**: Aprende qué son las etiquetas, los elementos y los atributos, y arma el "esqueleto" de tu primera página.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=PENDIENTE-L2)
- **Consejos clave**: Usa `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>` y `<body>`. Toda etiqueta que se abre, se cierra: `<p>...</p>`.
- **Práctica**: [Clic para programar](https://codepen.io/PENDIENTE-L2) 👈 **¡Comienza al instante!**

### Lección 3: Elementos HTML comunes (10 minutos)
- **Descripción**: Agrega encabezados, párrafos, listas, imágenes y enlaces para darle contenido real a tu página.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=PENDIENTE-L3)
- **Consejos clave**: `<h1>` a `<h6>`, `<p>`, `<ul>`/`<ol>` con `<li>`, `<img src="..." alt="...">` y `<a href="...">`.
- **Práctica**: [Clic para programar](https://jsfiddle.net/PENDIENTE-L3) 👈 **¡No necesitas registrarte!**

### Lección 4: Introducción a CSS (10 minutos)
- **Descripción**: Dale color y personalidad a tu HTML: aprende a conectar CSS con HTML y a usar selectores de etiqueta, clase e id.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=PENDIENTE-L4)
- **Consejos clave**: Regla CSS = selector + propiedad + valor, por ejemplo `h1 { color: purple; }`. Prueba `color`, `background-color`, `font-family` y `font-size`. Usa `.clase` para varios elementos y `#id` para uno solo.
- **Práctica**: [Aplica estilo con un clic](https://codepen.io/PENDIENTE-L4) 👈 **¡Comienza al instante!**

### Lección 5: Estilos simples: centrar, bordes y diseño (10 minutos)
- **Descripción**: Entiende el modelo de caja, centra contenido, agrega bordes y esquinas redondeadas, y organiza elementos en fila con Flexbox.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=PENDIENTE-L5)
- **Consejos clave**: `text-align: center;`, `margin: 0 auto;`, `padding`, `border: 2px solid black;`, `border-radius` y `display: flex;` con `gap`.
- **Práctica**: [Clic para programar](https://codepen.io/PENDIENTE-L5) 👈 **¡No necesitas registrarte!**

### Lección 6: Proyecto final: tu página de perfil (12 minutos)
- **Descripción**: Combina todo lo aprendido para crear una página de perfil con tu foto, tus gustos y enlaces favoritos.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=PENDIENTE-L6)
- **Consejos clave**: Primero el contenido (HTML), luego el estilo (CSS). Guarda tus cambios seguido.
- **Proyecto Final**: [Crea tu perfil](https://replit.com/@PENDIENTE-L6) 👈 **¡Guarda y comparte!**

### Lección 7: Errores comunes y próximos pasos (5 minutos)
- **Descripción**: Revisa los errores más frecuentes de principiantes, aprende a encontrarlos con la herramienta Inspeccionar del navegador y descubre dónde seguir aprendiendo.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=PENDIENTE-L7)
- **Consejos clave**: Etiquetas sin cerrar, olvidar `;` o `}` en CSS, rutas de imágenes incorrectas. Valida tu código y explora [MDN Web Docs](https://developer.mozilla.org/es/).
- **Comparte tu trabajo**: [Envía tu creación](https://forms.gle/PENDIENTE-FORM)

## 🛠️ Instrucciones de configuración

Para **estudiantes** no hace falta instalar nada: basta con abrir los enlaces de **Práctica** de cada lección.

Si quieres revisar el código fuente de este repositorio:

1. Haz clic en el botón verde **Code** → **Download ZIP**, o navega los archivos directamente en GitHub.
2. Abre la carpeta de la lección que quieras en `/starter-files` (punto de partida) o `/completed-examples` (resultado final).
3. Copia el contenido de `index.html` y `styles.css` en los paneles HTML y CSS de [CodePen](https://codepen.io/pen/) para verlo funcionando.
