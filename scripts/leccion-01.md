# Guion · Lección 1: ¿Qué es un sitio web? (5 min)

**Objetivo:** que el estudiante entienda qué es una página web y qué papel cumplen HTML y CSS.
**Editor:** CodePen (pen con `starter-files/leccion-01`).
**Recurso visual:** analogía de la casa (HTML = estructura/ladrillos, CSS = pintura/decoración).

| Tiempo | Pantalla / Texto en pantalla | Narración (voz en off) |
|---|---|---|
| 0:00 – 0:30 | Montaje rápido de páginas conocidas (buscador, red social, tienda). Texto: **"¿Cómo se hacen estas páginas?"** | "Todos los días usas páginas web: para ver videos, buscar tareas o chatear con tus amigos. ¿Alguna vez te preguntaste cómo se construyen? En este curso vas a crear la tuya, ¡sin instalar nada!" |
| 0:30 – 1:30 | Diagrama: Tú → Navegador → Internet → Servidor → Página. Texto: **"Sitio web = conjunto de páginas"** | "Un sitio web es un conjunto de páginas guardadas en una computadora llamada servidor. Cuando escribes una dirección, tu navegador, como Chrome o Firefox, pide esa página y la muestra en tu pantalla." |
| 1:30 – 2:45 | Animación de la casa: primero solo paredes (HTML), luego pintada y decorada (CSS). Texto: **"HTML = contenido · CSS = estilo"** | "Toda página web tiene dos partes principales. HTML es la estructura: los textos, las imágenes, los botones. Es como las paredes de una casa. CSS es el estilo: los colores, los tamaños y la decoración. Es como pintar y decorar esa casa." |
| 2:45 – 3:45 | Se abre CodePen con un ejemplo. Se señalan los paneles HTML, CSS y el resultado. Anotación con flechas. | "Para practicar usaremos CodePen, un editor que funciona en el navegador. A la izquierda escribimos HTML, en el centro CSS, y abajo vemos el resultado al instante. Mira: si cambio este texto… ¡la página cambia sola!" |
| 3:45 – 4:30 | Ícono ⏸️ grande. Texto: **"Pausa y practica: cambia el título y el color"** | "Ahora te toca a ti. Pausa el video, abre el enlace de práctica en la descripción y cambia el título por tu nombre. Luego cambia la palabra `blue` por `red` en el CSS. ¿Qué pasó?" |
| 4:30 – 5:00 | Resumen en pantalla con 3 viñetas. | "Resumen: un sitio web es un conjunto de páginas; HTML pone el contenido y CSS le da estilo. En la próxima lección escribirás tu primera página HTML desde cero." |

**Notas de producción**
- Zoom del navegador al 150 % para que el código se lea bien.
- Sin nombres de autores ni logos en pantalla o en el código.
