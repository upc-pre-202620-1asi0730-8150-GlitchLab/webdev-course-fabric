# Guion · Lección 3: Elementos HTML comunes (10 min)

**Objetivo:** usar encabezados, párrafos, listas, imágenes y enlaces.
**Editor:** JSFiddle (fiddle con `starter-files/leccion-03`).

| Tiempo | Pantalla / Texto en pantalla | Narración (voz en off) |
|---|---|---|
| 0:00 – 0:30 | Texto: **"Hoy: le damos contenido real a tu página"** | "Ya tienes el esqueleto de tu página. Ahora vamos a llenarla con títulos, listas, imágenes y enlaces." |
| 0:30 – 2:00 | `<h1>` a `<h6>` mostrados uno debajo de otro. Texto: **"Un solo `<h1>` por página"** | "Los encabezados van de `<h1>`, el más importante, a `<h6>`, el más pequeño. Úsalos como los títulos de un cuaderno: un título principal y subtítulos. No los uses solo para agrandar letras; para eso está CSS." |
| 2:00 – 3:00 | `<p>` con texto, `<strong>` y `<em>` resaltados. | "Los párrafos van en `<p>`. Si quieres resaltar una palabra importante usa `<strong>`, y para dar énfasis, `<em>`." |
| 3:00 – 4:30 | Lista de "Mis hobbies" con `<ul>` y "Mis pasos para un sándwich" con `<ol>`. | "Hay dos tipos de listas. `<ul>` es una lista con viñetas, cuando el orden no importa. `<ol>` es una lista numerada, cuando el orden sí importa. Cada elemento de la lista va en `<li>`." |
| 4:30 – 6:30 | `<img src="..." alt="Un gato durmiendo">`. Anotaciones en `src` y `alt`. Demostración rompiendo el `src`. | "Para imágenes usamos `<img>`. Es especial porque no tiene etiqueta de cierre. `src` indica dónde está la imagen y `alt` describe la imagen con palabras. `alt` es muy importante: lo leen las personas que usan lectores de pantalla y aparece si la imagen no carga. Mira, si escribo mal la dirección… sale el texto alternativo." |
| 6:30 – 8:00 | `<a href="https://developer.mozilla.org/es/" target="_blank">`. Clic en vivo. | "Los enlaces usan `<a>` con el atributo `href`. El texto entre las etiquetas es lo que se puede clicar. Si agregas `target="_blank"`, el enlace se abre en una pestaña nueva." |
| 8:00 – 9:30 | Ícono ⏸️. Texto: **"Pausa y practica: arma tu lista de favoritos"** | "Pausa el video y abre el enlace de práctica. Agrega: un `<h2>` que diga Mis favoritos, una lista `<ul>` con tres cosas que te gusten, una imagen con su `alt` y un enlace a tu página favorita." |
| 9:30 – 10:00 | Resumen visual con los 5 elementos. | "Con estos cinco elementos ya puedes escribir casi cualquier página. Pero todavía se ve simple… En la próxima lección la llenaremos de color con CSS." |

**Notas de producción**
- Usar imágenes libres de derechos (por ejemplo, de Unsplash o Pexels) con su URL directa.
