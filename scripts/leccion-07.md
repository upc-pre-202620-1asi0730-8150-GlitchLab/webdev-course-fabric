# Guion · Lección 7: Errores comunes y próximos pasos (5 min)

**Objetivo:** reconocer y corregir los errores más frecuentes y saber cómo seguir aprendiendo.
**Editor:** CodePen (pen "con errores" de `starter-files/leccion-07`).
**Tema añadido:** usar las herramientas del navegador (Inspeccionar) para encontrar errores.

| Tiempo | Pantalla / Texto en pantalla | Narración (voz en off) |
|---|---|---|
| 0:00 – 0:20 | Texto: **"Todos cometemos errores"** | "Equivocarse es parte de programar, incluso para los expertos. Lo importante es saber encontrar y corregir los errores." |
| 0:20 – 2:00 | Página rota. Se corrigen uno por uno: etiqueta sin cerrar, falta `;` en CSS, falta `}`, comillas sin cerrar en `src`, nombre de clase distinto entre HTML y CSS (`.Destacado` vs `.destacado`). | "Veamos los cinco errores más comunes. Una etiqueta sin cerrar hace que el estilo se "derrame". Si falta un punto y coma o una llave, CSS ignora la regla. Si las comillas no se cierran, la imagen no carga. Y ojo: CSS distingue mayúsculas, así que `Destacado` no es lo mismo que `destacado`." |
| 2:00 – 3:15 | Clic derecho → **Inspeccionar**. Se selecciona un elemento y se ve su CSS; se cambia un color en vivo. | "Tu navegador tiene una herramienta secreta: clic derecho y **Inspeccionar**. Ahí ves el HTML y el CSS de cualquier elemento y puedes probar cambios en vivo. Tranquilo: lo que cambies ahí no se guarda." |
| 3:15 – 4:00 | Validador de W3C (validator.w3.org) mostrando un error. | "Otra ayuda: el validador de W3C revisa tu HTML y te dice en qué línea hay un problema." |
| 4:00 – 4:40 | Ícono ⏸️. Texto: **"Pausa y practica: encuentra los 5 errores"** | "Pausa el video. En el enlace de práctica hay una página con cinco errores escondidos. ¿Puedes encontrarlos todos?" |
| 4:40 – 5:00 | Enlaces en pantalla: MDN Web Docs en español, cuestionario y formulario para compartir. | "Para seguir aprendiendo, visita MDN Web Docs en español. Haz el cuestionario y comparte tu página de perfil. ¡Felicitaciones por terminar el curso!" |
